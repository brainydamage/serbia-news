# Сербия: новости

Агрегатор новостей о Сербии в духе [infomate.club](https://infomate.club): независимые, близкие к SNS,
государственные, региональные и иностранные СМИ, популярное с сербского Reddit и то, что сербы ищут в Google, на одной странице.

Чем отличается от infomate:

- заголовки видны целиком, без обрезки «…»;
- подводка из RSS видна при наведении на заголовок (на телефоне — по первому касанию), клик открывает статью;
- заголовки и подводки можно читать на русском (перевод Claude при сборке);
- оглавление разделов в закреплённой шапке;
- общая хронологическая лента с фильтром по лагерям — удобно сравнивать, кто как подаёт одну новость;
- переключатель латиница / кириллица для сербских текстов;
- поиск по заголовкам (не важно, латиницей или кириллицей вводить, с диакритикой или без);
- прочитанное помечается серым.

## Как устроено

- `sources.json` — разделы и ленты. Добавить издание: дописать `{"name", "site", "feed"}` в нужный раздел.
  Для не-сербских лент укажите `"lang": "en"` или `"ru"`.
  Чтобы выкинуть лишние разделы издания, добавьте `"exclude"` — список кусков адреса, например
  `"exclude": ["/showbiz/", "/zadruga/"]`. Так сейчас убраны шоу-бизнес, реалити и анонсы телеэфиров,
  а у N1 ещё и английская версия сайта.
  Если у сайта нет RSS (021.rs, RTV, Subotica.com, Kolubarske, Kruševac Grad, KoSSev, Kosovo Online), лентой служит поиск
  Google News по сайту: `https://news.google.com/rss/search?hl=sr&gl=RS&ceid=RS:sr&q=site:021.rs+when:2d`.
  Для таких лент сборка выкидывает страницы рубрик и не пишет издание после каждого заголовка.
  `"ranked": true` — не пересортировывать ленту по дате (у топа Reddit порядок — по популярности).
  Ленту Google Trends (`trends.google.com/trending/rss?geo=RS`) сборка узнаёт по адресу и разбирает отдельно:
  заголовок — поисковый запрос, ссылка и подводка — первая новость к нему, рядом — сколько было запросов.
- `build.py` — скачивает все ленты (только стандартная библиотека Python 3.10+) и пишет `site/index.html` и `site/data.json`.
  Если лента временно недоступна, берутся её новости из прошлой сборки.
  Reddit без авторизации отвечает примерно на один запрос в минуту, поэтому за сборку обновляется
  один сабреддит — тот, что дольше всех ждал (`FEEDS_PER_BUILD` в `build.py`). После первого запуска
  остальные сабреддиты появятся за следующие несколько сборок.
- В шапке — средний курс евро и рубля к динару (Народный банк Сербии, через kurs.resenje.org), погода и
  качество воздуха в Белграде (Open-Meteo). Всё без ключей, обновляется при каждой сборке; город задаётся
  в `CITY` в `build.py`. Если источник не ответил, его часть строки просто не показывается.
- `template.html` — сама страница: данные встраиваются в неё, отрисовка на JS.
- `.github/workflows/build.yml` — пересборка каждые 20 минут и публикация на GitHub Pages.

## Запуск локально

```bash
python3 build.py
python3 -m http.server 8765 -d site
```

## Перевод на русский

Заголовки и подводки переводит Claude (модель Haiku 5.5) прямо при сборке, на странице появляется переключатель
«Srpski / Русский». Каждая новость переводится один раз: готовые переводы лежат в `cache/translations.json`.
Порядка 2000 новостей в день обходятся примерно в $5 в месяц; сколько стоила конкретная сборка, `build.py` пишет в конце.

1. Создать ключ в [консоли Anthropic](https://console.anthropic.com) (Settings → API keys) и пополнить баланс.
2. Один раз поставить библиотеку:
   ```bash
   python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
   ```
3. Добавить ключ в `~/.zshrc`:
   ```bash
   export ANTHROPIC_API_KEY="sk-ant-..."
   ```
4. Собирать так:
   ```bash
   .venv/bin/python build.py
   ```

Без ключа или без библиотеки сборка работает как раньше, просто без перевода.
Модель и правила перевода (как писать имена и т.п.) задаются в начале `translate.py`.

Названия компаний, банков и клубов модель передаёт русскими буквами, а не переводит по смыслу
(«Поштанска штедионица», а не «Почтовая сберегательная касса»). Если какое-то название всё равно
переводится или пишется по-разному, добавьте его в `glossary.json`:
`{"sr": "Poštanska štedionica", "ru": "«Поштанска штедионица»"}`. Падежи и алфавит не важны:
запись найдёт и «Poštanskoj štedionici», и «Поштанска штедионица». После правки заново переведутся
только новости с этим названием.

Кандидатов в глоссарий ищет `.venv/bin/python audit_names.py`: модель просматривает готовые переводы
и выписывает названия, переведённые по смыслу (около цента за прогон). Список нужно отбирать вручную:
среди находок бывают и неудачные советы вроде «Financial Times» → «Файненшл таймс».

Затем открыть http://localhost:8765.

## Публикация на GitHub Pages

1. Создать репозиторий и запушить туда эту папку.
2. В настройках репозитория: Settings → Pages → Source: **GitHub Actions**.
   Для перевода: Settings → Secrets and variables → Actions → New repository secret,
   имя `ANTHROPIC_API_KEY`, значение — ваш ключ.
3. Actions → build → Run workflow (или просто пуш в `main`).

GitHub отключает расписание в репозиториях без коммитов дольше 60 дней — тогда достаточно нажать «Enable workflow» во вкладке Actions.
