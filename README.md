# Vestomat — новости Сербии

**https://vestomat.rs** · по-русски: **https://vestomat.rs/ru/**

Агрегатор новостей о Сербии в духе [infomate.club](https://infomate.club): на одной странице — независимые,
близкие к SNS, государственные, региональные и иностранные СМИ, сербский Reddit и то, что сербы ищут в Google.

- заголовки целиком, подводка — при наведении (на телефоне — по первому касанию);
- перевод заголовков и подводок на русский (Claude, при сборке);
- вид «по изданиям» и общая лента с фильтром по разделам — удобно сравнивать, кто как подаёт одну новость;
- латиница / кириллица для сербских текстов, поиск без разницы в алфавите и диакритике;
- курс динара, погода и воздух в Белграде.

## Как устроено

- `sources.json` — разделы и ленты. Издание добавляется строкой `{"name", "site", "feed"}` в нужный раздел;
  `"lang"` — для не сербских лент, `"exclude"` — куски адреса, которые выкинуть (шоу-бизнес, реалити),
  `"ranked": true` — не сортировать по дате. Сайты без RSS читаются через поиск Google News по сайту.
- `build.py` — скачивает ленты (стандартная библиотека Python 3.10+), переводит новое и пишет `site/`:
  страницы `/` и `/ru/`, `data.json`, `sitemap.xml` и содержимое `static/`.
  Если лента недоступна, берутся её новости из прошлой сборки.
- `translate.py` — перевод через Anthropic API с кэшем в `cache/translations.json`;
  `glossary.json` — названия, которые нужно передавать русскими буквами, а не переводить по смыслу.
- `template.html` — сама страница: данные встраиваются в неё, отрисовка на JS.
- `.github/workflows/build.yml` — сборка и публикация на GitHub Pages.

## Запуск локально

```bash
python3 build.py
python3 -m http.server 8765 -d site
```

Затем открыть http://localhost:8765. После правок в `template.html` ленты заново качать не нужно:
`python3 build.py --render-only` пересоберёт страницы из уже скачанного `site/data.json`.

Для перевода нужны библиотека `anthropic` и ключ API:

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
export ANTHROPIC_API_KEY="sk-ant-..."
.venv/bin/python build.py
```

Без ключа сборка работает, просто без перевода. На GitHub ключ задаётся секретом репозитория `ANTHROPIC_API_KEY`.
